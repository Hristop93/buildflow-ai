# Buildflow AI — backend core (Phase 1 foundation)

Изчислителното ядро на платформата, доказано срещу Excel еталона.
Чисто Python ядро, без външни зависимости — работи навсякъде.

## Структура
```
backend/
  data/seed.py          # нормативното знание (актове, процедури, такси, правила)
  engines/
    rules.py            # сглобява активния граф от параметрите
    fees.py             # такси = основа × ставка, с цитат към член+акт
    schedule.py         # критичен път (CPM)
    economics.py        # IRR/NPV/LCOE/payback + присъда + Monte Carlo
  tests/test_engines.py # доказва съответствие с Excel: 420 дни, 39 870 лв, IRR 11,8%
SPEC.md                 # пълната функционална спецификация (планът за разработка)
```

## Пускане на тестовете
```bash
cd buildflow-ai
python backend/tests/test_engines.py
# очаквано: 7/7 tests passed
```

## Какво е готово
- Четирите машини, доказани срещу еталона.
- Seed данните за наземна ФЕЦ (структурата е финална; числата са представителни).
- Правилата (include/exclude/switch) работят: смяна на параметър → различен граф.

## Какво следва (в Claude Code, по реда от SPEC.md, Фаза 1)
1. PostgreSQL схема + Alembic миграции (по §3 от SPEC.md).
2. Loader: seed.py → базата.
3. FastAPI обвивка около машините + endpoint `/projects/{id}/recalc`.
4. Админ панел (приоритет — твоят инструмент за въвеждане на данни).
5. Auth + wizard + проектен изглед (секции Резюме/Маршрут/Такси).

## Принцип
Машините НЕ ползват LLM — всичко идва от seed/базата. Това гарантира
проследимост и възпроизводимост. Еталонът (Excel) остава тестът за вярност:
всяка промяна в машините трябва да продължи да дава 420 / 39 870 / 11,8%.
